# avc-attrition-analysis

Machine learning analysis for Case Studies in Data Science - Individual Task 1.

Two models:Logistic Regression and Decision Tree trained on the IBM Employee Attrition
dataset to predict employee attrition, in the context of a People Data & Insights Analyst
role at Australian Venue Co.

Dataset source: https://github.com/IBM/employee-attrition-aif360/blob/master/data/emp_attrition.csv
